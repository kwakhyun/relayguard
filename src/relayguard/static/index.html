    외부 사본과 함께 보관하세요

    해시 체인은 저장된 기록 사이의 연결을 검사합니다. 로그 전체를 다시 쓰거나 삭제하는 행위까지 막아 주지는 못해요.

    1. 현재 기록 내보내기검증 결과와 전체 감사 기록을 JSON 파일로 내려받아요.
    2. 서버 밖에 사본 보관하기현재 해시와 내보낸 파일을 별도의 안전한 저장소에 보관하세요.
    3. 이후 기록과 비교하기보관한 시점의 해시를 기준으로 변경 여부를 확인하세요.

    키가 만료될 때까지 사용할 총량 선택

    총량은 분이 바뀌어도 초기화되지 않아요. 비워 두면 총량을 제한하지 않으며, 위의 요청 속도와 응답 크기 제한은 그대로 적용됩니다.

    키는 지금 한 번만 표시돼요. 안전한 비밀 저장소에 보관한 뒤 창을 닫아 주세요.

    아직 저장 여부를 확인하지 않았어요. 지금 닫으면 키 원문을 다시 볼 수 없습니다.

      이 릴레이 키를 폐기할까요?

      이 키를 사용하는 다음 요청부터 차단돼요. 폐기한 키는 다시 활성화할 수 없습니다.

      응답을 전달하기 전에도 폐기 여부를 확인해요. 이미 원본 API에서 처리된 작업은 취소되지 않습니다.
